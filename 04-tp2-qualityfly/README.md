# TP2: QualityFly

Menú de consola de una aerolínea con siete opciones: ver vuelos disponibles, agregar al carrito, pagar pasajes, registrarse, iniciar sesión, cerrar sesión y salir. Las acciones están separadas en métodos (`MostrarVuelosDisponibles`, `Carrito`, `Registrarse`, `IniciarSesion`, `CerrarSesion`). Esta versión está comentada línea por línea, explicando qué hace cada parte.

Para correrlo, abrí el `.sln` con Visual Studio y presioná F5.
