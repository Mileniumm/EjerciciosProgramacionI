# Simulacro del parcial 1: bonificación por rendimiento

Pide el rendimiento de un empleado (1 bueno, 2 regular, 3 malo) y su salario, y calcula la bonificación con un `switch`: 10% si es bueno, 5% si es regular y nada si es malo. Si se ingresa una letra en vez de un número, avisa que el valor no es válido.

Para correrlo, abrí el `.sln` con Visual Studio y presioná F5.
