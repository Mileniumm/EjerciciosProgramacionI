# Listas: gestor de tareas

Ejercicio 4 de listas. Carga cinco tareas en una `List<string>`, las muestra, permite modificar una buscándola con `IndexOf` y al final vacía la lista con `Clear()`. El código tiene comentarios que explican cada bloque.

Para correrlo, abrí el `.sln` con Visual Studio y presioná F5.
